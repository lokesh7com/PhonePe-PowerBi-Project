# 📱 PhonePe Transaction Analysis Dashboard | Power BI Project

An interactive **PhonePe Transaction Analysis Dashboard** built using **Power BI** to analyze digital payment trends, transaction volume, transaction value, insurance adoption, loan distribution, and user engagement across India. The dashboard provides valuable insights into the growth of digital payments and helps stakeholders make informed business decisions through interactive visualizations.

---

# 📌 Project Overview

The **PhonePe Dashboard** transforms raw digital payment data into meaningful business insights using interactive reports and visualizations.

The dashboard enables users to analyze:

- Total Transactions
- Total Transaction Value
- Transaction Volume
- Insurance Performance
- Loan Distribution
- User Growth
- Payment Category Trends
- Quarterly & Yearly Performance

Using **Power Query**, **DAX**, and **Power BI**, the project demonstrates how Business Intelligence can be used to monitor and analyze India's digital payment ecosystem.

---

# 🎯 Business Problem

India's digital payment ecosystem generates millions of transactions every day. Without an interactive reporting solution, it becomes difficult to:

- Monitor transaction growth
- Compare state-wise performance
- Analyze payment categories
- Track insurance adoption
- Evaluate loan distribution
- Understand user engagement trends
- Support strategic business decisions

A centralized Power BI dashboard helps stakeholders monitor the overall performance of the PhonePe ecosystem and identify growth opportunities.

---

# 🎯 Goal of the Dashboard

The dashboard is designed to help business users:

- Monitor digital payment performance
- Analyze transaction trends
- Track insurance penetration
- Monitor loan distribution
- Understand customer usage patterns
- Identify business growth opportunities
- Enable data-driven decision-making
